[OpenRouter](https://openrouter.ai/) is an AI Gateway. It's trivially easy to
get an OpenRouter API key and try out hundreds of models. In this guide we walk
through setting up OpenRouter on Val Town in a couple minutes.

## Quick setup

1. Remix our [openrouter](https://www.val.town/x/templates/openrouter) template
2. Grab an API key from [OpenRouter](https://openrouter.ai/)

## How it works

Our template uses the OpenRouter TypeScript SDK to connect to hundreds of
available models. It's a small demo for the purpose of trying out new (or old)
models, to get a feel for their speed, intelligence, and cost. And of course you
could use OpenRouter on Val Town to build any application you want that needs to
run some inference with model flexibility. Like a
[Slack agent](/guides/slack/agent) or an
[AEO researcher](https://www.val.town/x/templates/aeo-research).
